# CP-02.1 — cenários

## Reais

Duas observações do processo atual, sem ação no FM entre elas: build VERIFIED, leitura de até 1 GiB por captura, 25 segundos de limite de busca, zero candidatos. Estado inicial: processo aberto; treinador humano e clube controlado não confirmados independentemente. Resultado esperado: registrar observações sem autorizar. Resultado: cumprido; busca parcial sem cadeia reproduzida. Comparação vazia não prova continuidade.

## Cenários A–J solicitados

| Cenário | Situação |
|---|---|
| A Ceará/humano | Apenas processo atual observado; controle humano não confirmado |
| B outro clube/humano | Não executado |
| C mesmo clube/outro save | Não executado |
| D mesmo clube/data | Não executado realmente; CP-02 possui teste sintético de bloqueio |
| E mudança de emprego | Não executado |
| F desempregado | Não executado |
| G dois humanos | Não executado |
| H carregar outro save | Não executado |
| I fechar/reabrir FM | Não executado |
| J clube e seleção | Não executado |

Roteiro manual futuro: em cópias de saves preparadas pelo usuário, capturar A com clube/treinador conhecidos; carregar B manualmente e coletar durante/depois do carregamento; repetir com mesmo clube/data, desemprego e múltiplos humanos. Registrar estado esperado e evidência independente da interface em cada coleta. Usar arquivos de saída novos; comparar sem interpretar mudança como save automaticamente. Não alterar carreira principal para fabricar cenários.

Reprodução da ferramenta: `python engenharia_reversa/investigar_identidade.py --max-mb 1024 --seconds 25 --output <arquivo-novo.json>`. Comparação: `python engenharia_reversa/investigar_identidade.py --compare <A.json> <B.json> --output <comparacao-nova.json>`. Arquivos existentes são recusados.

## Sintéticos

10 testes cobrem cadeia válida somente observacional, ponteiro nulo/inacessível, vtable incorreta, cadeia incompleta, referência alterada, zero objetos, aparecimento/desaparecimento, entrada inválida e comparação sem prova de carreira. Não foram implementadas fixtures específicas de humano/IA, gerações, desemprego e vínculo ambíguo porque não há regra semântica desenvolvida para esses campos; são lacunas de cobertura, não testes aprovados.
