# UX-01 — Relatório de testes

02/11/2026. Windows 11 x64, Python 3.14, PySide6 6.12.0, PyInstaller 6.22.3. Base Git 2e9a103 com alterações anteriores preservadas. Nenhum save nem campo real do FM foi alterado durante os testes.

Com PYTHONPATH=ferramentas/qt-tools;ferramentas/build-tools;ferramentas, executar python testar_ux01.py: 18 testes aprovados (navegação, ações sem aprovação, formulários, modelo, invalidação, delegação ao motor, falha de leitura após aplicação, recuperação desconectada, thread Qt, exceção de worker, consolidação de sync e fechamento ocupado). QtTest usado no processamento do loop. Mocks não equivalem a operação real no FM.

Regressões aprovadas: testar_pf012.py (10), testar_pf011.py (9), testar_pf01.py (6), testar_sg01.py (18), testar_sg01_interface.py (1), testar_sg011.py (20), testar_sg011_interface.py (1), testar_sincronizacao_hibrida.py (13), testar_sincronizacao_interface.py (4), testar_compatibilidade.py (23), testar_identidade.py (15), testar_contratos_dados.py (26), testar_indice_clubes.py (7). Scripts testar_emprestimos.py, testar_patrocinios.py, testar_uniformes.py e verificar.py retornaram 0.

Capturas reais de widgets renderizados offscreen, com snapshot sintético identificado como Clube de teste, em docs/ux/capturas. Incluem todas as páginas, desconectado, confirmação e erro; 1366x768 e 1600x900. Inspecionadas imagens de Finanças, Dashboard e Infraestrutura. Fontes inicialmente apareciam como quadrados no plugin offscreen; corrigido registrando Segoe UI no ambiente de teste. Não é captura de uma carreira real nem homologação nativa de todas as escalas Windows.

Falha inicial de inicialização por nome MainWindow.event conflitante com QMainWindow.event: handler renomeado on_result e self-check fonte passou. Self-check compilado inicialmente falhou ao importar QtCore; diagnóstico identificou icuuc.dll externo do Poppler. O isolamento desse arquivo permitiu passar; build atualizado para prevenir contaminação de PATH. A execução final reproduzível e tamanho são registrados abaixo.

Validação de distribuição: build final com PATH explícito passou no self-check sem isolamento manual de DLLs, iniciada com diretório temporário. bin-ux01 contém 113,41 MiB; plugins de plataforma coletados pelo PyInstaller. Avisos GPL/LGPL e nota de licenciamento incluídos. O atalho principal não foi alterado. A janela compilada iniciou com o plugin Windows, identificou FM23 aberto e apresentou Ceará Sporting Club no seletor. Aprovação manual em verificação somente leitura; resultado e navegação registrados na continuidade deste relatório.

Homologação nativa realizada na compilação Qt em Windows: sincronizou com FM aberto, mostrou Ceará Sporting Club, abriu confirmação e aprovou manualmente, exibiu snapshot real; navegação em Finanças e Recuperação, leitura dos journals e ciclo periódico do monitor observados sem escrita administrativa. A janela de teste iniciada por esta execução foi encerrada após a inspeção. Corrigido o feedback após monitor e acrescentado teste de descarte de proposta obsoleta; suíte Qt final com 18 aprovados. Nenhuma operação econômica real foi executada. Demais resoluções/DPI e funcionalidades comerciais/gráficas completas continuam pendentes.
