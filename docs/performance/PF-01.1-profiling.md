# PF-01.1 — Profiling

Instrumentação `medir_pf011.py`: wrappers temporários com perf_counter_ns, ID por operação, fase, duração e resultado. Exportação sem endereços e sem conteúdo de memória. Origem é diagnostic; não há telemetria permanente manual/monitor. Wrappers são restaurados ao sair. Fases de build incluem fingerprint (tempos aninhados, não somar); memória conta chamadas guardadas dos leitores; sqlite_query mede a consulta, sem abertura da conexão. O tempo PowerShell é total do subprocesso, sem separar criação/import/encerramento.

Windows 11 x64, Python 3.14, FM23 23.2.0+1771058 aberto. Três pipelines antes e depois, candidato conhecido em índice. Nenhuma escrita de teste em memória real ou save. Leituras SQLite e índice local fazem parte da busca. Não se controlou cache do SO nem a carga externa. Hash completo custa a maior parcela. Guard mantido integralmente; não foi introduzido cache arriscado.
