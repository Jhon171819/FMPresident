# UX-01.2 — Benchmarks

O benchmark comparável disponível continua sendo o de UX-01.1: inicialização sintética Qt mediana 104,329 ms e Tkinter 2.310,867 ms, sem conexão FM. Não foram medidos nesta issue CPU, memória, primeira pintura nativa, leitura real durante sincronização ou escrita administrativa.

Não há base para declarar superioridade geral do Qt. A investigação do alocador não executou escritas apenas para medir tempo.
