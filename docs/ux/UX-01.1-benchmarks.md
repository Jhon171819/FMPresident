# UX-01.1 — Benchmarks

Comando reproduzível: `PYTHONPATH=ferramentas/qt-tools;ferramentas/build-tools;ferramentas python medir_ux011.py`.

Ambiente: Windows 11 x64, Python 3.14, dez inicializações sintéticas de cada janela, sem conexão FM. Resultado salvo em `docs/ux/UX-01.1-benchmarks.json`:

| Interface | Mediana | p95 | Mínimo | Máximo |
|---|---:|---:|---:|---:|
| Qt | 104,329 ms | 172,705 ms | 76,605 ms | 286,307 ms |
| Tkinter | 2.310,867 ms | 5.975,518 ms | 1.120,336 ms | 7.810,602 ms |

Este cenário instancia janelas sem FM e não mede sincronização, leitura de memória, primeira pintura nativa, CPU, memória ou tarefa demorada. Portanto registra uma comparação de inicialização sintética, não uma prova de superioridade geral do Qt.
