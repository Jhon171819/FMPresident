# UX-01.1 — Distribuição

`python construir_qt.py` produziu a distribuição separada `bin-ux011/FMPresidenteQt.exe` (aprox. 127,31 MiB). O build usa PyInstaller 6.22.3, PySide6/Shiboken6 6.12.0, PATH controlado para evitar a colisão `icuuc.dll` do Poppler e coleta plugins Qt necessários. `--self-check` gerou `dados/autoteste-qt.json` com `ok: true`.

O build não substitui `bin-pf012` nem o atalho principal. A entrada frozen resolve os assets/dados do diretório do projeto, como as versões anteriores.

Licenciamento: avisos GPL/LGPL estão em `avisos-qt/` e a revisão oficial está documentada em UX-01. Não se declara conformidade legal completa: ainda é necessário revisar correspondência de binários, avisos, fontes correspondentes e possibilidade de relink antes de uma distribuição pública.
